# Release Readiness Checker
## purpose
Checks a version and environment and reports whether a release is ready.
## Setup
Use Python 3. No extra packages. Clone the repo, then run the tests.
## Usage
Run: python3 checker.py 1.0.0 staging
## Branching
Keep main releasable. Do feature work on shortlive branches.
## Contribution
Open an issue, use a feature branch, add tests, and open a Pull Request.
BUG: staging is always ready
